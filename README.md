# CongratulationDay

Мини-приложение для GitHub Pages: вводите имя друга, выбираете стиль и получаете поздравление с праздником текущего дня.

## Возможности

- Автоматический поиск праздника на **сегодня** через публичный API `date.nager.at`.
- Резервная локальная база праздников, если онлайн-источник не вернул событие.
- Три режима поздравления:
  - Обычный
  - Строгий деловой
  - С юмором
- Кнопка **«Переделать»** для повторной генерации.
- Опциональная AI-генерация через Kie API (Gemini 3.1 Pro endpoint) при наличии API key (если ключ не указан, используется встроенный генератор).

## Запуск локально

Откройте `index.html` в браузере или используйте любой static server.

## Публикация на GitHub Pages

1. Запушьте репозиторий на GitHub.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или ваша ветка), папка `/root`
4. Сохраните настройки. Через 1–2 минуты сайт будет доступен по ссылке вида:
   `https://<username>.github.io/CongratulationDay/`
